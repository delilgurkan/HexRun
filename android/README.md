# HexRun Android (Kotlin / Jetpack Compose) + Wear OS

Native Android client for HexRun. The React Native app in `apps/mobile/` is kept only as a
behaviour/copy reference. Shared rules: `docs/NATIVE.md`, API: `packages/contracts` + `docs/API.md`.

| Module | What | Builds where |
|---|---|---|
| `:core` | Pure Kotlin/JVM: geo, `LoopTracker`, H3 (`com.uber:h3`), Turkish formatting, events (Europe/Istanbul), palette + neighbour rule, Hat segments, API models + `ApiClient` (OkHttp, single shared refresh), `RunSession` (append-only journal, crash recovery), offline `RunQueue`, deep links, phone↔watch `WatchPayload`, Turkish strings (`co.hexrun.core.i18n.S`) | anywhere with JDK 17+ |
| `:app` | Phone app `co.hexrun.app` (minSdk 26, target 35): Compose + Material 3, Navigation Compose, MapLibre, Fused Location foreground service, Credential Manager (Google), FCM, WorkManager, Wearable Data Layer | Android SDK |
| `:wear` | Wear OS companion (Compose for Wear OS) — live HUD mirrored from the phone | Android SDK |

`settings.gradle.kts` only includes `:app`/`:wear` when an Android SDK is present (`ANDROID_HOME`,
`ANDROID_SDK_ROOT`, `local.properties` `sdk.dir`) or `-PwithAndroid` is passed. The Android Gradle Plugin is put
on the root build classpath under the same condition, so `./gradlew :core:test` needs only a JDK and Maven Central.

## Commands

```bash
./gradlew :core:test                      # vectors from ../shared/test-vectors + client logic tests (JDK only)
./ci.sh                                   # CI: core + app unit/Robolectric tests, lint, assembleDebug, wear
./gradlew -PwithAndroid :app:installDebug # device / emulator
./gradlew -PwithAndroid :app:bundleRelease :wear:bundleRelease   # Play upload (see Signing)
```

`:core` tests read `shared/test-vectors/*.json` (generated by `npx tsx packages/core/scripts/vectors.ts`)
through the `hexrun.vectors` system property and must match the TypeScript engine exactly.

## Setup

1. JDK 17 or 21, Android SDK with platform 35 (Android Studio Ladybug+ or `sdkmanager "platforms;android-35" "build-tools;35.0.0"`).
2. `local.properties`: `sdk.dir=/path/to/Android/sdk` (Android Studio writes it).
3. Configuration — Gradle property (`-P…` / `~/.gradle/gradle.properties`) or environment variable:

| Name | Default | Purpose |
|---|---|---|
| `HEXRUN_API_URL` | `https://api.hexrun.co` | API base (`/v1` is appended). For the emulator + local server use `http://10.0.2.2:3000` (and allow cleartext in a debug network config if needed). |
| `HEXRUN_MAP_STYLE_URL` / `HEXRUN_MAP_STYLE_URL_DARK` | OpenFreeMap positron / dark | MapLibre style JSON. Any MapLibre-compatible style works (MapTiler, Stadia, self-hosted). |
| `HEXRUN_GOOGLE_WEB_CLIENT_ID` | empty (Google button shows "not configured") | **Web** OAuth client id used as `serverClientId` by Credential Manager. Also create an **Android** OAuth client for `co.hexrun.app` with your debug/release SHA-1. The server verifies the ID token audience. |
| `HEXRUN_FIREBASE_APP_ID`, `…_API_KEY`, `…_PROJECT_ID`, `…_SENDER_ID` | empty | Manual Firebase init when no `google-services.json` |
| `HEXRUN_VERSION_CODE` / `HEXRUN_VERSION_NAME` | `1` / `1.0.0` | Release versioning |
| `HEXRUN_TERMS_URL`, `HEXRUN_PRIVACY_URL`, `HEXRUN_LICENSES_URL` | hexrun.co pages | Legal links |

### Firebase / push (FCM)

Put `app/google-services.json` (git-ignored) from the Firebase console for package `co.hexrun.app`; the Google
Services plugin is applied only when that file exists (`ci.sh` writes it from the `GOOGLE_SERVICES_JSON` secret).
Without it the app still builds; if the four `HEXRUN_FIREBASE_*` values are set Firebase is initialised manually,
otherwise push is disabled. After sign-in, when notifications are allowed, the FCM token is sent with
`PUT /v1/me/push-token {token, platform:"android", provider:"fcm"}`. Tapping a push opens `data.url`
(`hexrun://run?defend=…`, `hexrun://duel/revenge/…`, `hexrun://notifications`).

### Deep links / App Links

`hexrun://…` (all screens, see `core/…/deeplink/DeepLink.kt`) and verified App Links for
`https://hexrun.co/invite/<code>`, `/r/<path>`, `/app/<path>` (and `/en/…`). The site must serve
`/.well-known/assetlinks.json` with the release (and Play App Signing) SHA-256 fingerprint for `co.hexrun.app`.
Strava OAuth opens in Custom Tabs and returns via `hexrun://integrations?connected=strava`.

### Signing & Play internal testing

```bash
export HEXRUN_KEYSTORE_PATH=/abs/path/upload.jks HEXRUN_KEYSTORE_PASSWORD=… HEXRUN_KEY_ALIAS=upload HEXRUN_KEY_PASSWORD=…
export HEXRUN_VERSION_CODE=42 HEXRUN_VERSION_NAME=1.0.0
./gradlew -PwithAndroid :app:bundleRelease :wear:bundleRelease
```

Upload `app/build/outputs/bundle/release/app-release.aab` (and the Wear bundle, as a Wear OS form-factor release)
to the **Internal testing** track in Play Console with Play App Signing enabled. Without the keystore variables
the release bundle is unsigned. Phone and watch must share `applicationId` and signing key for the Data Layer.

## Notes

- **H3 natives**: h3-java ships `android-arm64` / `android-arm` `.so` files as JAR resources; the `extractH3Natives`
  task repackages them as `jniLibs` (`arm64-v8a`, `armeabi-v7a`). x86/x86_64 emulators have no H3 native → cell
  functions are unavailable there (map hexes are not drawn, the app keeps working). Use an ARM64 image (Apple
  silicon) or a device.
- **Location**: rationale screen before any system dialog; fine location is required to run, background location is
  optional (the run is recorded by a `foregroundServiceType="location"` service with the "Koşu sürüyor" notification).
  Location denied → the app opens but the run button is locked ("Ayarları aç").
- **Run recovery**: every GPS point / pause / resume is appended to `files/active-run.jsonl`; if the process is killed
  the run is replayed into `LoopTracker` on next start (or when the sticky service restarts).
- **Offline queue**: finished runs are queued (`files/kv/hexrun.runQueue.v1`), retried with exponential backoff +
  jitter, idempotent by `clientRunId`; permanent 4xx are dropped (kept as failed). WorkManager retries when online.
- **Wear OS**: the phone publishes `WatchHud` to `/hexrun/hud` (key `json`, ≥1 Hz while running), events to
  `/hexrun/event`, and handles `/hexrun/command` (pause/resume/finish) in `WatchCommandService`. Standalone watch
  recording is out of scope.
- **Fonts**: Archivo (variable: weight + width axes) and IBM Plex Mono are bundled in `res/font` (OFL, see
  `assets/licenses`). HUD digits use the condensed width (wdth 75), headings 115.
- **Strings**: Turkish only for now (`co.hexrun.core.i18n.S`, ported from `apps/mobile/src/i18n/tr.ts`).
